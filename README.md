# منصة تسهيل التعليمية (Tasheel Study Platform)

منصة تعليمية تفاعلية مخصصة للطلاب لشرح وتبسيط المواد الدراسية، تشمل الفسيولوجيا وتطبيقات الحاسب العلمية.

## المميزات
- نطق صوتي أصلي مدمج لجميع المصطلحات الطبية بالإنجليزية.
- أسئلة تفاعلية فورية لاختبار الفهم مع شرح دقيق لأسباب الخطأ والصواب لكل خيار.
- إمكانية تجربة وتغيير الإجابات بحرية تامة لاستكشاف كافة الخيارات.
- اختبار شامل (10 أسئلة) مع عداد درجات ولوحة تقييم حية.
- دعم الوضع الليلي والنهاري (Dark / Light Mode).
- إمكانية ترجمة الأسئلة من الإنجليزية إلى العربية بضغطة زر.
- تصميم طبي عصري بدون إيموجي وباستخدام أيقونات فيكتور (SVG) احترافية.
