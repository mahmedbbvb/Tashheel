6. ⏱️ طريقة الحل في 10 ثواني

  1. دور على كلمة السؤال: What / Which / Where / How many...
  2. دور على كلمة المطلوب: function / location / type / definition...
  3. فتش عن NOT أو EXCEPT أو FALSE: دي أهم خطوة تمنعك من الوقوع في الفخ.
  4. حدد الموضوع: السن؟ الجهاز العصبي؟ membrane؟ computer؟
  5. اقرأ الاختيارات: بعد ما عرفت وفهمت المطلوب بدقة.
  6. ترجم المعنى العام: وليس كل كلمة حرفيًا.
Where is the ganglion located? Where = أين + ganglion = العقدة العصبية + located = موجودة/تقع
➡️ المطلوب: مكان الـ ganglion.

7. 🔎 فرّق بين الجملة والسؤال

أحيانًا تأتي جملة طويلة قبل السؤال. الجملة تعطيك المعلومة، أما الجزء الذي بعد ذلك فيحدد المطلوب.

The Somatic Nervous System is primarily responsible for voluntary movement. Which option is correct?

المعلومة: الجهاز العصبي الجسدي مسؤول بشكل أساسي عن الحركة الإرادية.

السؤال: أي اختيار صحيح؟

المطلوب: اختيار الإجابة التي توافق المعلومة.

Which of the following best matches the concept described by this statement?

Which = أيّ | following = مما يلي | best matches = يتوافق بشكل أفضل | concept = مفهوم | statement = العبارة

➡️ المعنى: أيٌّ مما يلي يتوافق بشكل أفضل مع المفهوم الذي تصفه العبارة؟

8. 🦷 أمثلة من بنك Tashheel

Dental Anatomy primarily studies the morphology and details of the teeth. Which option is correct?

المعنى: تشريح الأسنان يدرس بشكل أساسي شكل وتفاصيل الأسنان. أي اختيار صحيح؟

المطلوب: اختيار المصطلح الذي يطابق المعلومة.

Which of the following best matches the concept described by this statement?

المعنى: أيٌّ مما يلي يتوافق بشكل أفضل مع المفهوم الذي تصفه هذه العبارة؟

المطلوب: اختيار أفضل تطابق.

A student is reviewing this point: “Dental Anatomy primarily studies the morphology and details of the teeth.” Which answer should the student select?

المعنى: طالب يراجع هذه النقطة... أي إجابة يجب أن يختار؟

المطلوب: الإجابة المطابقة للنقطة المذكورة.
